# Velvet Stories v2.8.5 — Message Character Shortcut

- Moves **Open character** from the top story menu into the per-message three-dot action sheet.
- The shortcut is visible immediately for any single-character chat message, without opening a second More menu.
- Opening the profile closes message actions safely and browser Back returns to the same chat.
- Group Stories keep the shortcut hidden because there is no single unambiguous character.
