VELVET STORIES v3.31.0 — DIALOGUE GENOME + CONVERSATIONAL NATURALISM

Voice release focused on how characters actually talk, not just what personality labels say.

Included:
- Dialogue Genome: sentence architecture, question habits, explanation tolerance, topic resistance, false starts, public/private shifts, mood shifts and relationship-language drift.
- Anti-Interview Engine: stops repeated answer → question loops.
- Anti-Therapist Engine: blocks generic counselor/service language unless the role truly calls for it.
- Anti-Perfect-Reaction: characters may hesitate, answer partially, mis-time a joke, protect pride or need another beat.
- Selective Answering + Conversational Carryover: characters do not process user messages like support tickets.
- Vocabulary ownership + cadence bans: generic romance/witty-college phrasing is aggressively filtered.
- Dialogue Drift Watch: long chats compare current dialogue against the character fingerprint and recent cadence.
- Voice Examples Learning: selected Learning Room samples are analyzed into the saved voice fingerprint instead of only being pasted as examples.
- Same Scene Voice Lab: Clone Lab now judges reaction logic AND sentence mechanics blind.

The update deploys the character-chat Edge Function because the dialogue engine lives in Supabase.
