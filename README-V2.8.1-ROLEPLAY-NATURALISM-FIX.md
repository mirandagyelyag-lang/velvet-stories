# Velvet Stories v2.8.1 — Roleplay Naturalism Fix

This release makes the narrative engine react to the visible turn instead of inventing conflict.

- React, don't invent: unsupported motives, jealousy, attention-seeking and accusations are rejected.
- Stock AI-romance body-language stacks trigger one bounded repair.
- Repeated jaw/grip/gaze/voice patterns across recent replies are detected.
- Physical distance created by the user is respected.
- Rumors remain rumors and social hyperbole is not treated as literal danger.
- Side characters remain real social participants instead of jealousy props.
- Dialogue can be brief, messy and human; replies no longer need padding to feel complete.
- Repair instructions require a genuinely different social choice, not synonym-swapping.
