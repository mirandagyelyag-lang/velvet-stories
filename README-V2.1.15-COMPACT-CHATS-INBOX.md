# Velvet Stories v2.1.15 · Compact Chats Inbox

- Chat rows always use the character name, never a conversation title such as “New Story”.
- The most recent message is the only message preview.
- Date/time moved into the former “You:” line under the preview.
- Read rows no longer reserve a right-side metadata column; unread rows only show the unread badge.
- Chat hero, search spacing and mobile list cards are more compact.
- ALL / UNREAD / FAVORITES / ARCHIVED controls are significantly smaller, including their counters.
- Preserves the Stories theme shell, Light / Comfort / Dark, and existing unread evidence state.
