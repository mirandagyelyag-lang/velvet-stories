VELVET STORIES v3.31.1 — NATURAL VOICE LOCK

Hotfix for Dialogue Genome overperformance.

Fixes
- Banter saturation: sarcasm no longer snowballs turn after turn.
- Ordinary-answer priority: short user lines cannot become clever mini-monologues.
- Canon specificity gate: no fake texts, grades, classes, shared memories or named familiarity just to make a reply feel alive.
- Nickname ownership: derived nicknames are not invented from the user name.
- Immediate stop rule: if the user tells the character to stop joking/teasing/doing something, the next reply cannot repeat it as another bit.
- Repeated umbrella/door/shoulder choreography is treated as a real loop.
- Severe dialogue naturalism failures now spend the one bounded repair instead of being dismissed as style-only.
- v3.31 verifier now accepts compatible later patch versions.

No UI changes. Character-chat must be redeployed.
