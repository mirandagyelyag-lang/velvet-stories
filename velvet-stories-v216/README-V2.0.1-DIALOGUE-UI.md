# Velvet Stories v2.0.1 · Dialogue UI

This release changes presentation only. It does not change the roleplay prompt, model, memory engine, scene engine, or generated text.

## Mobile chat changes
- Character replies are visually grouped like conversation messages rather than wide book pages.
- Narration is smaller, tighter, and quieter.
- Paragraphs that begin with dialogue are rendered as distinct dialogue beats.
- Quoted dialogue inside narration is highlighted without changing the original text.
- Character replies use a soft warm surface; user replies remain visually distinct.
- Message spacing is reduced so the chat has conversational rhythm.
- Swipe, scroll, message actions, streaming, Memories 2.5, Relationship, Director, and AI Status are unchanged.
