# Velvet Stories v2.5.0 · Living Story Suite

This release layers six story-management upgrades on v2.4.1 without replacing Velvet's existing continuity, memory, or Storycraft architecture.

## 1. Relationship Map
Relationship Pulse now includes a grounded visual map for single and group stories. It shows the active persona and real story cast without fake percentages. Group entries use persisted cast state when evidence exists.

## 2. Story Dashboard
Story Hub opens as a living dashboard with current chapter, recap, persona, world, relationship, cast, latest meaningful beat, recent story memories, open threads, chapters, saved moments, and alternate timelines.

## 3. Better Memory Control
The existing memory editor now exposes an Important flag, explicit story-only versus all-stories scope, merge-into-this-memory behavior, and visible "Why Velvet remembers this" provenance. Existing category editing remains intact.

## 4. Favorite Moments + Quotes
Message actions use Save moment for bookmarks and keep Quote, Copy, Edit, Branch, Rewind, and Save to memory. Story Hub surfaces bookmarks as Favorite moments.

## 5. Story Chapters
The narrative engine creates a chapter on first use and closes/starts chapters only when a grounded large time or phase transition is visible. Messages and timeline events receive chapter numbers. Chapters remain bounded.

## 6. Character Awareness 3.0
The continuity ledger distinguishes known facts, suspicions, rumors, and intentionally faded minor details. Private knowledge does not spread between characters without a visible transfer, and off-screen characters cannot learn new scene events.
