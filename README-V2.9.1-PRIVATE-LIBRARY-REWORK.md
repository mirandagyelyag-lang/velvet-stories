# Velvet Stories v2.9.1 · Private Library Rework

- Stories and Chats now communicate distinct jobs: archive/manage stories vs jump back into active conversations.
- Discover is replaced in the visible UI by Characters, a private cast library without fake public popularity/discovery sections.
- Memories is character-first: profile-art cards labeled `CHARACTER · Name`, saved thoughts inside each card, and global importance filtering.
- Profile & Access is a real account sheet with account/session/private-library status, edit profile, and log out.
- Chats rows have more spacing, stronger card separation, and a calmer mobile layout.
- Character Studio Lite and all narrative-engine fixes from v2.9.0 remain intact.
