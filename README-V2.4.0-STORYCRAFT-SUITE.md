# Velvet Stories v2.4.0 · Storycraft Suite

Six connected story tools built on top of Story Intelligence 2.0:

- editable user and character messages, with AI edits preserved as response versions
- inline response-version navigation and swipe alternatives
- Group Stories with a real multi-character cast
- Personas 2.0 selection before a story starts, with strict identity isolation
- smarter lore retrieval that sends only relevant world entries
- Search Velvet across stories, characters, messages, memories, timeline beats and lore

Group Stories preserve `character_id` as the primary lead for backwards compatibility and store the full cast in `group_character_ids`.
