# Orvayne narrative continuation release

The source and semantic review gate now runs before saving or displaying a character reply. It rejects near-verbatim repeats and reviews paraphrased repeated beats, perception, unsupported history and user agency. A repaired reply discards the rejected draft’s state updates. The existing crisis support route remains before fiction.

Chase’s new-story greeting now establishes a physical approach and speaking distance, without prescribing a user conversation or reaction. Existing story messages are not rewritten.

Validation: 46 deterministic tests pass; TypeScript parser and module syntax checks pass. Authenticated preview testing confirmed independent movement rather than a third repeated waiting beat. Model review is fallible and adds latency; this is not a guarantee of narrative quality or complete factual correctness. The legacy generation pipeline remains upstream.
