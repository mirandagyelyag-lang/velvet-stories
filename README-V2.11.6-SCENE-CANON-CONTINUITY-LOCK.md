# Velvet Stories v2.11.6 — Scene Canon & Continuity Lock

Focused narrative patch on top of v2.11.5.

- Latest user-authored location/companions immediately become the active scene camera.
- Old-scene “Meanwhile, back on...” continuations are rejected when the user just moved the scene.
- Off-screen leads may reach the new scene through an incoming message/call without controlling the user.
- Retrospective continuity claims such as “had already been forwarded/sent/shared/given” require visible transcript or confirmed memory evidence.
- Silent continuation target is compressed to one meaningful 20–75 word beat.
- Recycled prop choreography (pen/keys/page/cup/phone loops) is repairable.
- Remaining polished Chase-style lines such as “sheer warmth in your voice” and “heartfelt sentiment” are treated as overwritten banter for casual characters.
- Keeps v2.11.4 deterministic npm install lock and v2.11.5 story-memory isolation.
