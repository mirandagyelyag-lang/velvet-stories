# Velvet Stories v3.49.33 · Human Memory + Personal History

Adds character-owned, salience-weighted, epistemically bounded memory. Characters remember gist and personal meaning rather than behaving like transcript databases; unresolved history can shape behavior without forced callbacks or exposition. Includes associative recall, forgetting/fuzziness for minor details, reconsolidation of beliefs without rewriting events, promises/open loops, shared-reference provenance, temporal humility, and anti-fake-nostalgia / anti-memory-dump guards.
