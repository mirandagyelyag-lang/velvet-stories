# Velvet Stories v3.50.1 · Instant Story Scene Diversity

Instant Story no longer treats student/university profile vocabulary as permission to default to campus, class, dorm, study spaces, or libraries. Academic settings are opt-in through the user's explicit Instant Story idea. Without an explicit setting, the backend selects a non-academic scene seed from ordinary life, social, transit, home, work, hobby, sport, nightlife, errand, and character-domain settings. The local fallback uses the same seed and the old student/outside-class fallback has been removed.
