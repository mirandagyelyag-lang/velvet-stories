# Velvet Stories v2.11.12 — Opening Pursuit Lock

Hotfix for first-turn charged pass-bys in new chats.

- Recognizes `passing by`, `passed by`, `brushing past`, and similar narrated departures.
- Movement wins over sarcastic `I missed you` affection classification.
- First charged pass-by for a high-initiative character requires active pursuit/follow-through.
- Watching the user leave, muttering to empty space, or reaching for a drink cannot satisfy the guard.
- Keeps explicit no-follow/no-touch boundaries intact.
