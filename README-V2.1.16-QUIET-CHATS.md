# Velvet Stories v2.1.16 — Quiet Chats

Chats was simplified into a calmer, message-first inbox:

- same Stories theme shell across Light, Comfort and Dark
- one new-chat action only
- compact text tabs instead of oversized filter pills
- no tab count bubbles
- borderless conversation rows with subtle dividers
- character name + time on one line
- last message directly below
- a tiny unread dot instead of unread badges
- smaller mobile hero, search, avatars and spacing
- no fabricated activity or typing state

No database or Edge Function changes are required for this release.
