# Velvet Stories v3.49.42 — Lean Dialogue Core

This release removes the accumulated v3.49.30–v3.49.41 humanization/style briefs from the visible narrative prompt and replaces them with one small semantic-first dialogue core. State engines and validators remain available.

Priority: understand the conversational move → resolve the concrete answer/motive → choose disclosure → speak plainly → add action only when physically necessary.

Production regressions covered include causal non-answers, semantic technicalities, survivor/survival quips, writerly dismissals, and performed body-language coolness.
