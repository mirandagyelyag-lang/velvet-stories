VELVET STORIES 3.52.47 · INSTANT STORY CONFLICT FIRST

Qué cambia
- Instant Stories deja de construir romance primero y problema después.
- El conflicto debe existir aunque se quite la atracción romántica.
- Cuando el mundo del personaje lo permite, hay al menos tres fuerzas con intereses distintos.
- NPCs con autonomía: información, lealtades, errores y relaciones propias.
- Peleas fuertes sólo por causas fuertes: mentiras, traición, secretos, confianza, lealtad, exposición, abandono, encubrimiento, responsabilidad, etc.
- Los celos sólo funcionan si la otra persona tiene peso real en la historia.
- Prohibidos los mecanismos artificiales: asiento guardado, ride por lluvia, conducir a través del campus, pedido extra favorito, objeto perdido, etc.
- El opening crea preguntas y NO las resuelve.
- Corta justo antes de una decisión/revelación/confrontación importante.
- Prohibidos finales tipo menú: “Which one?”, “your choice”, “come with me”, A/B.
- Target de longitud: 260–380 palabras. Techo del servidor: 420.
- Fallback viejo de takeout/errand/drive eliminado.

Cómo instalar
1. Extrae el ZIP.
2. En Git Bash ejecuta:
   bash ~/Downloads/APPLY-VELVET-3.52.47.sh
   (o usa la ruta donde dejaste el paquete)
3. Si termina con BUILD CORRECTO, ejecuta:
   bash ~/Downloads/DEPLOY-VELVET-3.52.47.sh

El instalador crea un backup dentro del proyecto antes de tocar los archivos.
