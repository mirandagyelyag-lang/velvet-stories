# Velvet Stories v1.4.6 · Velvet Monogram

Based on v1.4.4 Velvet Archive UI.

This version replaces the oversized VS decorations with:
- a repeating low-opacity VS monogram across the whole Stories background;
- soft ambient gradients that blend the pattern into the page;
- a tiny VS watermark inside story cards;
- lighter treatment in dark mode and mobile;
- no giant floating VS letters.
