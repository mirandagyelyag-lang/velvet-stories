# Velvet Stories v2.11.11 — Social Arc Grounding

This release hardens social continuity and ordinary supporting-character dialogue.

- A number/date/flirt target assigned to a friend remains assigned to that friend across the mini-arc.
- One-to-one plans cannot silently become group outings, double dates, or retroactive invitations.
- Explicit user corrections such as “your date, not mine” override a mistaken draft instead of spawning new attendees.
- Supporting NPCs cannot drift into an unnamed third romantic participant.
- Repeated “unbothered / didn’t even look up / darling / phone tapping” mannerisms are detected.
- Common over-written sitcom-style Jules lines are repaired into plainer conversational English.
- Social role validation now retains a wider recent window while consent/boundary interpretation remains local to recent turns.
- Scene relocation no longer contains the legacy instruction that encouraged an unlicensed incoming remote event.
- Existing deterministic install lock, Edge boot guard, memory isolation, Scene Focus Lock, Repair Rescue Guard, and romantic initiative behavior remain intact.
