# Velvet Stories v1.5.1 · Discover Moodboard

Built on v1.5.0 Stories Rebuild.

Discover deliberately uses a different layout language from Stories:
- oversized character spotlight
- side quick-picks
- mood/tag rail
- underline filters
- asymmetric poster mosaic
- poster-style CharacterCard presentation
- separate recoverable Trash view
- mobile layout changes into a compact image-first discovery feed

No story engine or character data logic was removed.
