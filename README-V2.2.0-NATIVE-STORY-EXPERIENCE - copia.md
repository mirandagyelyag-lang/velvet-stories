# Velvet Stories v2.2.0 — Native Story Experience

A single release focused on the places where Velvet still felt like a website rather than a private story app.

- Quieter, character-aware chat room and compact mobile header.
- Scene Director integrated into the composer while preserving Next Beat and Rewrite Last Reply.
- Character landing pages emphasize cover, relationship and the latest story.
- Character Studio gets a five-step editorial journey with Create with AI kept prominent.
- Settings becomes a compact control room organized around Appearance, Storytelling, AI & app, and Privacy.
- Secondary routes are lazy-loaded to reduce initial JavaScript work.
- Existing Light, Comfort and Dark themes, story engine, memory engine, reload routing, PWA behavior and Supabase data model are preserved.
