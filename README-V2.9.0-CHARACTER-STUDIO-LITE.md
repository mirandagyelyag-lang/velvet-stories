# Velvet Stories v2.9.0 · Character Studio Lite

Character creation now defaults to a calm Quick Create surface while preserving the complete six-step studio behind Fine-tune.

- One idea is enough; name, relationship and portrait are optional.
- AI fills the full advanced character profile in one generation.
- Generated characters show a compact review card rather than every field.
- Start chatting saves the character and opens a fresh story immediately.
- Fine-tune reveals the existing advanced six-step studio without losing the generated draft.
- Quick Variations make another character from the same premise with Softer, Colder, Funnier, More arrogant or Different dynamic directions.
- Discover character menus now include Duplicate & remix.
- Remix uses the source only as a depth template and explicitly asks for a new identity.
- Drafts, quick inputs and remix work are autosaved locally until explicit save.
