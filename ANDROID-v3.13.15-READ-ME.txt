VELVET STORIES ANDROID v3.13.15

Installer fix:
- Uses npm install so package-lock is synchronized with Capacitor 8.5.0 before the Android build.
- Android build uses .env.android.local generated from Desktop\velvet-stories\.env/.env.local.
- Vite PWA is disabled for Android builds.
- Android verification rejects sw.js, workbox files and manifest.webmanifest.
- Android recovery build uses http://localhost to avoid the old cached https://localhost PWA shell.

Run INSTALL-VELVET-ANDROID.ps1 from PowerShell or with the provided Git Bash command.
