# Velvet Stories v1.6.0 · Calm Editorial System

Built on v1.5.3 Discover Index + v1.5.0 Stories Rebuild.

Stories and Discover are intentionally preserved as the visual reference.
The rest of Velvet is harmonized around the same calm editorial language:

- warm cream / dusty rose / wine palette
- Cormorant display typography + Manrope UI typography
- fine borders and asymmetric editorial corners
- translucent warm surfaces instead of white boxes
- restrained shadows and gradients
- warm dark mode, never pure black
- unified sidebar + mobile bottom navigation
- calmer Character Profile
- calmer Character Studio / Create Character modal
- Memories, Personas, Lorebooks, Profile and Settings unified
- Chat redesigned as a quiet reading room with softer character bubbles
- mobile treatment prioritized, including composer and bottom sheets
- Auth and PWA/system UI harmonized

Implementation note: `src/styles/velvet-unified.css` is imported after App.css so it acts as the final visual system without rewriting working app logic.
