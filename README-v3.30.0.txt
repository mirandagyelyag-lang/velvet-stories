VELVET STORIES v3.30.0 — INTERACTION RELIABILITY

Focus: make existing Velvet features harder to break on mobile, desktop and installed PWA.

- Network/pointer modality state for UI reliability.

- PWA service-worker controller reload-loop guard.
- Legacy v3.28/v3.29 verifiers accept newer compatible releases.
- No Supabase schema or Edge Function change in this release.
