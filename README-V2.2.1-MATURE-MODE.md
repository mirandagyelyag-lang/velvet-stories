# Velvet Stories v2.2.1 — Mature Mode wiring

Mature mode is now a real per-story setting instead of a cosmetic control. It is stored on each conversation, reaches the Edge Function on every generation, and is preserved when branching a story.

When enabled it allows stronger adult themes, mature language, attraction, sensual tension and non-graphic consensual intimacy between adults. It does not override consent, character boundaries, continuity or provider safety; sexually explicit detail fades to black.
