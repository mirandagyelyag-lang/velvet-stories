# Velvet Stories v2.8.4 — Open Character Shortcut

## What changed

- Added **Open character** to the in-chat three-dot menu for single-character stories.
- The shortcut opens the existing full character cover/profile instead of creating a duplicate view.
- Browser/app Back returns to the exact chat because the profile is pushed on top of the current chat history entry.
- Group Stories keep the shortcut hidden because there is no single unambiguous character profile.
- No narrative engine or Supabase Edge Function changes are included in this release.
