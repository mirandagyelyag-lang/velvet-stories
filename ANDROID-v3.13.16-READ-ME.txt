VELVET STORIES ANDROID 3.13.16

This build fixes the failed Supabase env handoff.

The installer now recovers ONLY the public client key from:
1. common local env variable names,
2. previous local Velvet web/Android bundles,
3. your existing Supabase CLI login via `supabase projects api-keys`.

It never selects service_role, sb_secret_, or admin JWT keys.
The Android bundle is verified before the APK can be installed.
PWA/Service Worker output remains disabled in Android mode.
