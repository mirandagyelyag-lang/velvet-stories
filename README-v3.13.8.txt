VELVET STORIES v3.13.8 — NATIVE SCROLL RESET

This release removes the recent custom scroll stack and returns movement to the browser's normal one-finger scrolling.

Removed:
- Scroll Authority.
- Native Edges override.
- Custom pull-to-refresh.
- Fixed dock and compact page-end scroll patches.
- Draggable sheet-handle behavior.

Kept:
- Pulse character shelves from v3.13.5.
- Pulse null-title guard from v3.13.6.
- Existing feature-specific native overflow needed by long forms and sheets.
