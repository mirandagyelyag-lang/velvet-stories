# Velvet Stories v2.4.1 · Memory Categories

Memories is now organized into six calm, exhaustive library categories without changing the database schema:

- All
- Moments: events and conflicts
- Characters: people and character facts
- Relationships: relationship shifts and promises
- Preferences: likes, dislikes and boundaries
- Places: world and location details

Existing memories are classified from their current low-level `category` value, so no data migration is required. Pinned and recent section titles follow the selected category, while the advanced filter still exposes exact memory types and canon/history views.
