# Velvet Stories v3.50.2 · Character-Specific Nicknames

Fixes cast-wide nickname collapse (especially everyone calling Antonia “Toni”).

- Each character receives a stable, deterministic address lane based on character identity.
- For Antonia, the available name-derived lanes include Anto, Toni, Nia, Tonia, Antonia, and no nickname.
- Nicknames are optional and sparse, never a mandatory catchphrase.
- Existing creator/canon forms of address remain valid.
- A character should not borrow another character's nickname merely because it is common.
- The hard validator now recognizes the character's assigned lane instead of rejecting every new name-derived nickname.
