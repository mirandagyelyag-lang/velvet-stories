VELVET STORIES — ANDROID APP PROJECT
Version: 3.13.11
Package: com.velvetstories.app

This folder contains the current Velvet Stories web source plus an Android Studio / Capacitor project in android/.

FIRST SETUP ON WINDOWS (Git Bash):
  cd ~/Desktop/velvet-stories
  npm install
  npm run android:sync
  npx cap open android

AFTER WEB CHANGES:
  npm run android:sync

The Android project lives in:
  android/

Local secrets are intentionally NOT included.
