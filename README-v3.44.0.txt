VELVET STORIES v3.44.0
Narrative Arc Intelligence + Story Evolution

What this release adds
- Multiple parallel narrative arcs with independent states.
- Anti-stagnation detection for repeated scene/conflict loops.
- Relationship Pace Guard across attraction, trust, vulnerability, comfort and commitment.
- Arc dependencies so deep trust/payoffs require real prior evidence.
- Behavioral progression that allows regression without resetting character growth.
- Core personality protection: growth may change coping, habits and relationship behavior without replacing identity.
- Resolved Arc Locks so finished conflicts do not resurrect without a new cause.
- Setup -> development -> payoff awareness without railroading.
- Quiet-progress support: routines, trust, comfort and ordinary intimacy can count as development.
- Escalation Budget: progress does not require bigger drama.
- Dormant arcs remain available without being forced on-screen.
- Story Evolution Lab in Diagnostics.

Hard protections
- No forced confessions, breakups, crises or milestones to "advance" an arc.
- No turbo-romance from one good scene.
- No total reset to chapter-one behavior after earned growth.
- No personality replacement disguised as development.
- No payoff without setup/evidence.
- No reopening resolved arcs without a new causal event.
- No arc exposition replacing actual behavior.

Compatibility
- Built directly on v3.43.0 Long-Story Memory + Canon Compression.
- Preserves v3.43 memory architecture, v3.42 scene direction, v3.41 causality,
  v3.40 calendar/life simulation, v3.39 NPC ecosystem and all earlier engines.
- No new Supabase database migration required.
