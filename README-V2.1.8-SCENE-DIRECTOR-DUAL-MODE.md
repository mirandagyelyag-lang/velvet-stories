# Velvet Stories v2.1.8 · Scene Director Dual Mode

Scene Director now has two explicit behaviors:

- **Next beat** (default): keeps the current character reply untouched and saves the direction for the next character generation after the user's next turn.
- **Rewrite last reply**: immediately regenerates the latest character reply in place using the direction.

A queued Next Beat direction is shown above the composer and can be cleared before sending. The chat header, Immersive mode behavior, Discover themes, and Continuity Lock from v2.1.7 remain intact.
