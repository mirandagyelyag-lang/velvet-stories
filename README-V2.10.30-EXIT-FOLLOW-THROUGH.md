# Velvet Stories v2.10.30 · Exit Follow-Through

When the user physically leaves right after the character was rude, dismissive or hurtful, Velvet now treats passive watching + instant reset to the party/game/work as a repairable failure. The engine prefers one immediate follow-through beat first: calling after them, stepping after them, catching up, softening, or apologizing badly, while still preserving personality.
