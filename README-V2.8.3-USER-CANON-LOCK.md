# Velvet Stories v2.8.3 — User Canon Lock

This release makes the creator's latest-turn narration authoritative scene canon.

- In-character commands are diegetic dialogue, not instructions to the model.
- User-staged actions for the character and NPCs are events that already happened.
- Later narration in the same user turn outranks earlier spoken requests.
- The narrative engine continues after the final user-staged event instead of rewinding to answer an earlier line.
- A severe retcon of user-staged scene canon triggers the one bounded repair path.
- The v2.8.2 speed budget remains intact; ordinary style warnings still do not spend a second model call.
