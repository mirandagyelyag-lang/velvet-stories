# Velvet Stories v2.6.0 · Keepsake Suite

This release adds six story-preservation and immersion tools without changing the narrative generation contract:

- Character Voices / TTS using the device Speech Synthesis voices, persisted per character.
- Editable story covers with title, mood, and optional uploaded artwork.
- Book exports as direct PDF, HTML, and Markdown.
- Optional Ambient Story Mode with on-device procedural rain, city, café, campus, and fireplace ambience.
- Story snapshots, restore, portable JSON backup, and safety snapshots before restore.
- Catch Me Up on meaningful returns using the existing story recap and unresolved threads.

Database migration: `202608170005_velvet_v260_keepsake_suite.sql`.
No Edge Function deploy is required for this release.
