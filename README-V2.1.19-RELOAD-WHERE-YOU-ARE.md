# Velvet Stories v2.1.19 — Reload Where You Are

- Every main destination writes its location into the URL.
- Reloading Memories, Profile, Discover, Chats, Settings, Personas, Lorebooks or Diagnostics reopens that same destination.
- Open character profiles and active character chats also persist through a reload when the character still exists.
- Browser Back/Forward stays in sync with Velvet navigation.
- Uses query-string state, so Vercel can serve the SPA from `/` without additional rewrite routes.
