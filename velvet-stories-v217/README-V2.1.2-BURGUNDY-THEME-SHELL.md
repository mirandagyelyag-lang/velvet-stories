# Velvet Stories v2.1.2 · Burgundy Theme Shell

This release fixes two structural issues in the Burgundy Stories experience.

- Stories now has designed Dark, Light, and Comfort palettes instead of forcing the dark palette in every theme.
- The desktop sidebar is part of the full-height app shell while Stories/Chats is mounted. It cannot end halfway down the viewport.
- The Stories route owns the full document canvas in the active theme, including overscroll and empty states.
- The dedicated Chats inbox uses the same themed shell.
- Theme color follows Light, Comfort, and Dark on mobile.
- The existing Burgundy reference composition, story data, menus, AI, memories, and chat engine are unchanged.
