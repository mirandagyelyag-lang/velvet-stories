# Velvet Stories v2.1.12 · Exact Stories Shell

- Discover now mounts on the exact `chats-page--reference` surface used by Stories.
- Discover no longer paints any route/background layer of its own.
- Discover uses the same hero geometry as Stories with `discover` + `STORIES`.
- Mobile title and horizontal rails are contained so the page cannot widen past the viewport.
- Featured and Popular cards are slightly smaller on phones for more breathing room.
- Light, Comfort and Dark continue to come from the shared Stories theme tokens.
