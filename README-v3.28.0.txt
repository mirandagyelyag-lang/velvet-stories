VELVET STORIES v3.28.0 — RELATIONSHIP WORLD + STORY INTELLIGENCE

This release keeps Voice Identity, Character DNA 2.0, Reaction Engine, Autonomous Life and the Consequence Engine, then adds five systems aimed at making long stories feel less game-like and less repetitive.

1. RELATIONSHIP INTELLIGENCE 4.0
- Attraction, trust, comfort and commitment are separate axes.
- Attachment behavior changes access under pressure without becoming a visible diagnosis.
- Mixed signals are allowed only when desire and defense genuinely conflict.
- Threshold events (firsts, repairs, trust changes, commitment changes) alter expectations without rewriting personality overnight.
- Forgiveness is gated by repair evidence. One apology no longer restores every part of the old baseline.
- Romance pace uses the story preference (medium-fast / medium / slow) as behavioral pacing, not just more or less flirting.

2. EMOTIONAL CONTINUITY 4.0
- Emotional residue survives scene changes and reconciliations.
- Trust, warmth, humor, physical access, patience and assumptions may recover at different speeds.
- Conflicts can be partly repaired without disappearing.
- Residue changes behavior instead of causing repeated explanatory monologues.

3. SCENE VARIETY ENGINE 4.0
- Tracks recent scene signatures and conversational skeletons.
- Detects repeated question loops, cinematic tension beats and the campus/rain/library orbit.
- Avoids repeated accidental-touch beats and identical scene structures.
- Variety never teleports the user or breaks physical continuity; it changes the next earned context, activity, medium, initiator, social composition or ending.

4. NPC SOCIAL NETWORK 2.0
- NPCs have bonds with each other, not just with the protagonist.
- Supports asymmetric relationships and uneven knowledge.
- Rumors/secrets can move only through plausible witnesses or communication.
- NPC friendships, conflict, loyalty, romance and plans may progress without the lead character being present.

5. LONG-TERM MEMORY 4.0
- Core canon remains durable.
- Active memories guide current behavior.
- Low-salience trivia fades unless naturally reactivated.
- Behavior-changing memories receive extra weight when they altered trust, access, boundaries, habits or expectations.
- Velvet no longer uses random old trivia just to prove that it remembers.

6. WRITING STYLE DIRECTOR 1.0
- Reads the existing prose, dialogue, interiority and romance-pacing preferences.
- Changes prose density, camera and sentence texture without changing character identity.
- Detects repeated reply length, opening shape, question endings, gesture chains and therapy-summary cadence.
- Dialogue-forward stories stay dialogue-forward; restrained interiority stays restrained.

SAFETY / CONTINUITY
- Latest visible user turn remains highest authority.
- User dialogue, thoughts, feelings, motives, reactions and unstaged movement are never invented.
- Existing v3.27 autonomy/consequence state is retained.
- v3.28 signals persist only when the model has evidence; they do not invent user feelings.
- .env / .vercel are not included in this ZIP.
