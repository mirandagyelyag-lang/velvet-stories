# Velvet Stories v2.10.39 — Guarded Stream Commit

This release keeps the fast foreground stream for ordinary turns, but quarantines high-risk tension, departure, boundary, and motive-sensitive drafts until narrative validation accepts them. A rejected protected-interaction draft can no longer be shown optimistically or saved as a fallback when the one repair call fails.

Regression coverage includes the exact Chase porch case where `*i stay quiet but i walk*` was answered by watching her leave and staying by the pillar.
