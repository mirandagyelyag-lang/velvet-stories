# Velvet Stories v2.11.7 — Scene Focus Lock

This release fixes unwanted romantic-lead re-entry after the user moves the narrative camera to a new scene.

- A scene relocation such as `I was with Jules on my house` now stays with Jules/the home scene.
- An absent lead cannot be pulled back in through a convenient text, call, DM, notification, knock, or coincidence just to keep romance on-page.
- Remote contact remains allowed when the user initiates or mentions it, an active digital thread is already underway, or visible recent canon explicitly promised the contact.
- The exact unwanted `Jules at home -> fresh Chase text` regression is now a hard-repair-protected test.
- All v2.11.6 scene canon, dialogue grounding, memory isolation, npm lock, and Edge boot protections remain intact.
