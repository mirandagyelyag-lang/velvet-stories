# Velvet Stories v2.1.10 — Unified Discover Canvas

Discover now uses a single calm page canvas per theme instead of stacked gradients and tinted layers.

- Light: one warm ivory/blush canvas
- Comfort: one warm taupe canvas
- Dark: one deep burgundy-black canvas
- Sidebar and main Discover content share the same page background
- Removed Discover radial atmosphere overlays and the extra top-right glow layer
- Search, chips and cards keep subtle surfaces so controls remain readable
- Scene Director behavior from v2.1.9 is unchanged
