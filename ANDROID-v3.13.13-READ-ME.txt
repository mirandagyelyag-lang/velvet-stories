3. PWA update/repair UI is bypassed inside Capacitor Android.
4. Android build preparation automatically imports the existing public Supabase env from:
   Desktop\velvet-stories\.env or .env.local.

6. The Supabase project URL has a safe public fallback for project vwyudrmxatuukcbncats.
7. Android versionCode is bumped so the corrected APK replaces the prior installed build.
8. Native startup failures now show the real startup error instead of the misleading
   "Repair & reopen Velvet" PWA loop.
