# Velvet Stories v2.6.9 · Character Studio Mobile Fix

A targeted Android/mobile geometry patch on top of v2.6.8.

- Shows all six Character Studio journey steps at once on phones using a 3 × 2 grid.
- Removes the hidden horizontal journey carousel that cut off Voice / World / Opening.
- Prevents Portrait, Cover, Accent and form fields from widening the viewport.
- Keeps one-finger vertical scrolling and the existing Back / X escape paths.
- Preserves all v2.6.8 reliability, Story Engine and Safe Mode work.
