VELVET STORIES v3.13.9 — FLUID NATIVE SCROLL

This release fixes the remaining sources of stiff or delayed one-finger scrolling.

- Removes the document-level non-passive touchmove listener.
- Uses the browser document as the single page scroll owner.
- Restores native vertical overscroll behavior.
- Removes live backdrop blur from fixed mobile navigation and chat chrome.
- Keeps the v3.13.8 custom-scroll reset and Pulse fixes intact.
